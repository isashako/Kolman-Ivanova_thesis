Репозиторий создан для хранения актуальных кодов к выпускной квалификационной работе "Автоматизированный анализ пространственного распределения общественных мнений о качестве транспортного обслуживания по провинциям КНР" на факультете географии и геоинформационных технологий в НИУ ВШЭ.
## Содержание
- `baidu_tieba-scraping.py`: Код для автоматизированного сбора данных с Baidu Tieba.
- `weibo-scraping.py`: Код для автоматизированного сбора данных с Weibo.
